# AI Harness Agent Plugin Template

This template sets up a multi-agent task harness for Nicle IDE, supporting Antigravity, Claude Code, and OpenAI Codex.

## Included Commands

- `AI Harness: Run Reviewer Audit (Agent B)`: Runs static code review on current diffs.
- `AI Harness: Run Full Verification Pipeline (Agent C)`: Runs Svelte check and plugin validation.
- `AI Harness: Dispatch Coder Agent (Agent A)`: Prepares task envelope for Agent A.
- `AI Harness: Dispatch Reviewer Agent (Agent B)`: Prepares review envelope for Agent B.

## Development

Run commands using `Ctrl+Shift+P` in Nicle IDE.
